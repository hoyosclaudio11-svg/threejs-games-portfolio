## Cómo Ejecutar

1. Abrí `index.html` en tu navegador
2. Hacé click en cualquier juego para jugarlo
3. ¡No necesitás servidor — todo funciona con archivos estáticos!

## Hosting

Hosted on [GitHub Pages](https://pages.github.com/)

## Tech Stack

- **Three.js** — Motor 3D para WebGL
- **React** — UI framework (algunos juegos)
- **Vite** — Build tool con vite-plugin-singlefile
- **Tailwind CSS** — Estilos (algunos juegos)
